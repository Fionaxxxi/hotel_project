# G5 分层性能验收

本机合成数据，正常业务与万格协议压力分开运行。原始样本、分母、失败和最大值均保留；不外推真实OTA或生产SLA。

| 层次 | 样本与目标 | 实测 |
| --- | --- | --- |
| CSV 1万 / 10万解析 | 各5次，另有预热；P95≤120秒、峰值≤1024MiB | P95 0.989 / 13.217秒；峰值80.87 / 80.82MiB |
| XLSX 1万 / 10万解析 | 同上 | P95 2.107 / 27.584秒；峰值82.68 / 90.61MiB |
| JSON 1万 / 10万解析 | 同上 | P95 1.160 / 19.271秒；峰值81.79 / 81.99MiB |
| 指标查询 | 100次，P95≤2秒 | P95 0.1432秒，最大0.3358秒，失败0 |
| 审计查询 | 100次，P95≤2秒 | P95 1.3104秒，最大1.6330秒，失败0 |
| 正常自动链 | 10来源、30日、双渠道、5轮，并发1/2/4/2/4，预算120秒 | 50/50核验成功；P50 11.6795秒，P95 27.329秒，最大34.343秒 |
| 模型竞争中的关闭 | 10个真实AI_AVAILABLE任务，10次双渠道关闭，预算120秒 | 最大5.266秒 |
| 持续运行 | 3600秒、至少30次更新 | 3603.703秒、60次更新、311样本，业务失败0；结案61/61双关闭 |

协议100/1000/10000格各渠道单样本详见[协议基准](g5-protocol-benchmark.md)，单样本不计算P95。解析不包含后续业务物化；协议不包含完整核心队列。资源合计RSS包含数据库和模型，首2070.92MiB、末1908.14MiB、峰2255.61MiB，不是独占物理内存。到期队列最大20、过期租约最大0，最终本次来源待处理任务0。

全局死信14→18的4条来自恢复演练旧来源，并非本次负载；仍未解决。隔夜另发现连接池临时超时导致单Worker退出，补丁与最终回归另记，60分钟测量在该补丁之前。历史失败和额外20秒积压探针失败不删除，正式链预算始终为120秒。

最终回归还暴露重新开售25秒检查窗口失败。SQL模板剖析定位外盒回补和任务范围查询缺少显式tenant条件，两条累计约30.5秒；补齐后使用已有索引，相同专项14.92秒通过，未改窗口和断言。参见[修复前](g5-reopen-query-profile-before.json)、[修复后](g5-reopen-query-profile-after.json)及[专项JUnit](g5-reopen-query-fix-tests.xml)。原始失败与未改代码偶然通过结果都保留，不能把后者当修复证明。

原始证据：[解析](g5-parse-benchmark.json)、[查询](g5-query-benchmark.json)、[负载](g5-load.json)、[持续运行](g5-soak.json)、[结案与风险](g5-soak-closure.json)。
