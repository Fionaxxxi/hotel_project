# G5 安全验收范围

实际OpenAPI中75个受保护操作的未登录及审计员权限探测通过，见[操作矩阵](g5-security-matrix.json)。跨租户对象、独立审批、租户RLS连接池复用、越权导出、上传/压缩包边界、公式注入、策略与模型输出注入、恢复路径栅栏等负测包含在[最终回归](g5-tests.xml)。公开入口及开发登录单独按契约验收，不冒称所有URL均需登录。

登录PBKDF2校验及共享数据库限流已实施；日志字段脱敏、CSV控制字符公式防护、只读有界审计导出和摘要篡改检测已验证。浏览器实际显示恶意来源文本，未创建对应img元素或触发执行标记，跨租户回放返回隐藏/不存在，见[浏览器报告](g5-browser.json)。

当前配置秘密精确扫描见[扫描结果](g5-secret-scan.json)。公开交付包排除.env、运行库、原件和日志，逐文件SHA-256校验；只证明本次扫描范围，不能认证未知历史秘密。摘要不是第三方签名。进程级loopback访问保护不是OS沙箱；当前开发身份系统不构成生产身份安全认证。
