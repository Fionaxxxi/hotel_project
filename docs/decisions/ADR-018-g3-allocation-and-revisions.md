# ADR-018：保守曝光、两级版本与确定性分片

采纳，2026-10-27。按来源池/住宿日冻结buffer与渠道额度，记录曝光保留；未知写入或下调未核验前不释放。调拨先减并确认后增，不把本地取消视为远端撤销。

desired_revision表示业务目标，delivery_revision表示实际远端顺序。修复只能原样重放有效审批目标，新增执行序号/key，不改原快照。CONTENT manifest冻结wire content与逐chunk hash；每个池/日、计划/日各算一格。最高接纳版本与逐cell实际应用分开，旧请求真迟到也在远端事务内拒绝。

G2旧曝光须显式读取/关闭；旧协议关闭序号在HTTP前保留进source_control证据，G1编译共享同一锁并以保留/观察序号为下界。避免闭店指令用掉一个版本后下一次编译撞号。
