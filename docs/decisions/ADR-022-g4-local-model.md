# ADR-022：单一实际本地模型，只提供建议

采用官方多语言MiniLM固定revision的量化ONNX权重，独立子进程完成向量计算。权重约118MB；准备命令显式联网下载公开文件，正常运行离线。记录许可证、文件hash、适配器和实际输入输出。未启用任意远程代码或外部推理服务。

原因：先完成一项实际语义排序能力，避免同时引入生成式政策提取、多供应商模型和自主工具调用。房型与政策仍由确定性规则约束，硬冲突高于排序。隔离模型进程、全局运行许可、有限预算与可终止超时，防止模型占用分销lane。

代价：人工仍承担新映射决策；合成集上排序提升不等于NONE识别改善。本次对照在test上模型Top1较好但NONE误建议更多，故只显式请求辅助，不启用自动匹配批准。真实数据、替换模型及默认自动建议需要另行评估。
