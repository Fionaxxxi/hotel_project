# ADR-013：稳定分区与不可变合并generation

状态：采纳，2026-10-26。

采用单物业MASTER+每日CALENDAR、显式demo-v1序号流及快照authority。物业级事务锁串行合并，分区版本向量和严格来源序号防止回退。generation保存完整有界视图，每事实关联真实原始记录/遗留staging；tombstone独立保留。激活与outbox同事务。

不改G1历史快照或已执行迁移；v2生成兼容投影供原编译器消费，新generation输入加入依赖向量。旧G1激活不能覆盖受G2管理的来源。新增迁移005～007；已有004库和测试库均前向升级。

取舍：物业锁降低同物业并发，但避免全量view父指针丢更新；分区CAS仍允许无冲突日期推进。合并最多300000事实，投影有逐事实来源读取成本，不将流式解析性能等同激活性能。后续可改持久共享索引，必须保留原件血缘和原子切换。
