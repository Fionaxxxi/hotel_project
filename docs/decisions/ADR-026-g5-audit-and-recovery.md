# ADR-026：有界只读回放与保守恢复

日期：2026-10-28。状态：实施决定。

审计按实际版本边连接，RLS先于图遍历。采用节点、字节与时间预算，显式输出缺失与截断。原件位置沿provenance，不把投影record_number称物理行。脱敏导出采用hash manifest，不伪称外部数字签名。

备份采用短暂停机和三库写锁的稳定边界，不声称跨库原子事务或无停机快照。恢复到新库，先逐表/逐文件验证。远端状态不跟随核心回退；旧来源全部HELD、旧自动化暂停、旧任务保留取消记录。管理员显式读取新远端revision并只发STOP，实际验证后才能解除恢复HELD；新开售继续要求新快照/人审/reopen。

采用保守恢复意味着一些旧来源需人工接续，不能把新独立业务恢复说成所有旧业务自动恢复。RTO报告包含恢复、核验及新业务闭环，RPO单列备份之后的损失窗口。同盘包不代表整盘损坏容灾。
