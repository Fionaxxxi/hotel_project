# ADR-025：G5 本机权限与观测边界

日期：2026-10-28。状态：实施决定，实际验收以G5报告为准。

沿用四个真实角色和本机Bearer JWT，正常服务要求PBKDF2 verifier，不把总设计的Cookie会话描述成已实现。前端不持久化token，JWT用真实时钟；开发登录限速放数据库以跨进程生效。原.env保留演示驱动秘密并排除交付，不以“使用hash验证”掩盖本机还有秘密配置文件。

租户指标只读当前RLS事实。告警保存发现/确认/恢复历史；完整数量与最多10条明细样本分开。采集失败不会消除风险，也不介入业务发布或关闭许可。全局连接池统计放本机日志，避免通过租户接口侧漏其他租户请求活动。

普通日志JSON、UTC、轮转且不写原文/凭证/异常堆栈；原事实与审批仍保存在不可变业务表。进程级离线保护加固定本机适配器注册表，不宣称操作系统网络沙箱。真实部署的SSO/HTTPS/安全审计属于后续关卡。
