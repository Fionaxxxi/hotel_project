# ADR-014：原件、运行与尝试分离

状态：采纳，2026-10-26。

csv、openpyxl read_only、ijson迭代三种格式，以1000记录短事务提交暂存、行问题和检查点。恢复重新扫描并跳过已提交前缀；不承诺任意格式字节offset直接定位。预览和导出有界。

同batch及固定parser/template/normalizer参数hash只建一次run；新模板建新run，原件复用。当前两个模板ID是固定受支持规则版本，不是用户可执行脚本。哈希失败/结构错误为包级阻断，行错依日期隔离，重复自然键使相关分区阻断。主数据错误不可假设独立；合并引用错误在激活事务阻断，用户修正新包。

代价：JSON为每实体重扫、XLSX会重复打开，优先内存有界和恢复正确性。基准必须分别报告实际格式成本及峰值，不能填造p95。
