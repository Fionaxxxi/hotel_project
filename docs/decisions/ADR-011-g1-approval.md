# ADR-011：确定性编译与独立审批

日期：2026-10-26。状态：已实施。

候选为确定性规则，源酒店/房型/计划分别绑定确定的目标版本。酒店国家/城市、房型床型/人数/父级及政策字段逐项检查；规则排序不是概率。G1 不调用 AI，不自动批准首次映射。

compiler 接收冻结的数据结构，内部无网络或数据库读取；应用服务准备来源、映射、渠道编码、逐日价格与共享池。价格规则是代码注册的不可变版本 markup-10pct-v1，售价为 Decimal 净价×1.10，再按 USD 两位 ROUND_HALF_UP 量化。G1 不提供任意规则编辑器或 pricing_rule CRUD。

payload 包含一个酒店 bundle、计划日历及独立共享池日历。SIM-A 远端编码通过 channel_mapping 关联，酒店、房型、计划各有真实外键且只能有一个非空目标，不直接冒用内部 ID。全部相关目标版本和渠道编码冻结在 input_versions。

规范化版本 json-v1：UTF-8、排序字典键、紧凑分隔符、日期排序、金额字符串、禁止非有限数，排除 trace_id 等非业务元数据。相同有效输入复用快照；过期或被拒绝后编译新修订。数据库触发器保护业务载荷/依赖不被修改，状态独立更新。

审批由不同于 submitted_by 的 reviewer/admin 执行，绑定相同 payload_hash 和有效期。派发前复核来源当前指针、映射版本、政策、渠道能力、hash、时效及发起者成员资格。G1 不实现授权策略自动审批。

DEMO_CLOCK_ENABLED 仅在 development 可启用，固定业务时钟明确显示；令牌签发与审批期限始终使用真实时钟。来源 TTL 为24小时、未来容忍5分钟；这些为演示风险参数，不代表真实可订保证。
