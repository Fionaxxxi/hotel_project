# ADR-017：独立双模拟渠道与兼容边界

采纳，2026-10-27。保留SIM-A v1，追加独立/g3契约及SIM-B独立库/角色。现有SIM_B_TOKEN是旧SIM-A租户B身份，新渠道使用明确G3_SIM_B_TENANT_*变量。核心仅HTTP访问远端，无模拟库权限。

SIM-A同步每块30格，SIM-B先内容后异步日历每块10格。B采用布尔退款wire语义，只允许精确NONREF映射；72小时取消明确阻断。静态源合同暂限S-A，单来源物业一计划；不合并未知跨供应商库存。

代价：两个模拟器不能证明真实OTA准入。异步B由operation查询推动完成，完整远端读取一次有界JSON，无真实分页一致性承诺。
