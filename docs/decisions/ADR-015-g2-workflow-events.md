# ADR-015：数据库内确定性编排与至少一次事件

状态：采纳，2026-10-26。

采用PostgreSQL run/step/wait、outbox/inbox；业务变更和事件同事务，消费去重与效果同事务。人工映射/独立审批经事件唤醒相关流程，重新读依赖；不调用LLM决定状态，不跳过审批。成功步骤按输入hash保留。

事件可以重投/乱序；当前状态是事实源，旧映射版本明确STALE。拒绝、暂停、取消、过期和耗尽为显式状态/恢复命令。发布前再次检查审批、依赖和有效期，G1不可变快照规则保留。

取舍：没有任意DAG引擎或时间轮；独立路径以物业/listing为单位。有限事件重试后由管理员恢复原事件，禁止构造新ID掩盖失败。
