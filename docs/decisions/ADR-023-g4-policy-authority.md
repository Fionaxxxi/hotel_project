# ADR-023：固定人审锚点与逐快照机器授权

将管理员提出、独立审核批准的策略与每快照机器决策分开。内容不可变，控制状态带epoch；自动激活和自动发布分别授予。逐次及相对固定基准的价格限制同时执行，不能用连续小涨重置授权。源库存也比较，避免静态额度掩盖源变动。

G3快照以system.policy和不可变决策明确标识机器授权，不伪造人类签名。提交和新写入许可都核查当前policy epoch；源锁提供串行边界。已经取得许可的HTTP无法保证撤回，查询/对账继续。策略暂停不代表远端停售，实际关闭仍由G3办理。
