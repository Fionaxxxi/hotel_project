# ADR-024：订阅所有权、持久协调与诚实评估

G4显式订阅接管受管来源，G2在旧编排入口检查所有权，G1/G2旧售卖仍受G3接管栅栏。G4复用G2解析、分区CAS与G3额度/发布；独立inbox和持久轮询按当前事实接续，避免依赖通知恰好到达。初期每来源串行，不引入外部工作流服务。

新generation通过事实指纹和父级/标准版本复核获得映射复用证据，额度也必须绑定新activation。允许人针对明确快照处理异常，之后自动接续；硬不兼容不能用“风险确认”绕过。

评估固定200个合成query、50组物业、组级dev/test切分；原始预测、阈值、分母与置信区间一起保留。候选是预构建包，包内覆盖率不能冒充数据库检索召回；有限合成模板和无独立双人标注限制外推。功能验收与模型效果分别报告。
