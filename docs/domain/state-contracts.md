# 状态职责契约 v1

以下为后续阶段的概念状态职责；具体枚举以总设计状态机和对应实现契约为准，G0 不建立伪运行状态。

| 对象 | 状态推进者 | 合法推进依据 | 停止点与禁止行为 |
| --- | --- | --- | --- |
| 来源批次 | 接入应用服务 | 参数确认、校验、暂存及激活检查 | 坏行/不完整 snapshot 不可绕过激活闸门 |
| 映射 | 匹配服务提案、人工审核命令 | 来源与目标确定版本、审核理由、并发版本 | AI 无权直接批准，冲突等待人工 |
| 快照 | 编译器、审批服务 | 冻结输入、规范化业务 hash、有效审批 | 来源变化生成新快照，不能修改已批准载荷 |
| 发布任务 | 派发 Worker、查询和对账服务 | 有效审批、幂等键、租约、远端回执 | 超时进入结果未知路径，不能直接假定失败重发 |
| 工作流等待 | 服务端编排器 | 可信且去重的决策事件 | 客户端不能伪造恢复事件或跳过步骤 |

G0 当前仅 tenant/membership active/disabled 与供应商基础状态，没有上传、激活、映射或发布状态接口。
