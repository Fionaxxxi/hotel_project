# G1 发布结果未知

UNKNOWN表示本地无法确定远端是否执行，不是确定失败。不要换幂等键重新创建同一业务商品。

1. 核对租户、任务、快照revision/hash和SIM-A就绪状态，不在普通日志中打印令牌或完整连接串。
2. 页面使用“查询原操作并核验”；服务端查询同一idempotency_key和listing内容，不产生新发布写入。
3. 回执及listing的revision/hash一致，且重算内容hash一致后，任务变VERIFIED。记录所有回执，不覆盖历史。
4. 远端查询失败、操作未找到或内容不同，仍保持UNKNOWN并显示原因。G1自动查询最多5条回执后停止自动探测，可显式人工继续查询；不提供无安全依据的重发按钮。
5. 来源/映射已变化、审批失效或发起者失去权限时，未发送任务BLOCKED。需新快照/新审批；历史成功不能靠回滚数据库撤销。

测试故障在独立测试库启用“落地后延迟响应”，客户端超时后只查原operation。自动重试预算、复杂对账、外部漂移修复、紧急停卖和多worker fencing属于G2/G3，不以G1这一个故障案例代替完整可靠性验收。
