# G1 导入协议

POST /v1/imports，Authorization Bearer，multipart 表单使用同名 files 字段上传恰好六个文件：manifest.json、properties.csv、rooms.csv、rate_plans.csv、inventory.csv、rates.csv。字段内容沿用 contracts/files/v1。身份和租户来自服务器认证，不从 manifest 取值。

单文件≤5 MiB，实际文件总字节≤20 MiB，multipart 请求体另有21 MiB硬上限。文件名固定白名单，重复名字与超量文件拒绝。manifest结构不合法直接422，不创建伪批次；合法manifest中哈希或记录错误在确认阶段落入质量报告。

上传返回201及id/reused；重复包不会新增当前来源版本。GET批次返回manifest、version、状态、每类最多50条预览和activation_id。确认命令提交expected_version，落地issues和staging记录；G1同步处理有界小包，不返回虚构后台进度。激活命令提交当前version，完整性/来源序号/重叠范围/时效有冲突时409并回滚整个事务。

原件下载按artifact ID鉴权。报告记录序号从表头1开始，跨行CSV以解析记录序号定位。修正输入需新包，不覆盖原件或已有暂存记录。

G1暂不支持delta、ZIP、XLSX和数据JSON。所有默认参数是实现限制，不能当成性能实测。实际接口与请求体见生成的 contracts/openapi/g1.json。
